# Лабораторна робота №3

**Дисципліна:** Розробка програмного забезпечення на платформі Java

**Тема:** Опрацювання нескінченних послідовностей даних за допомогою ледачих (lazy) операцій Java Stream API, безпечне керування наявністю значень через Optional та створення кастомних проміжних операцій за допомогою Stream Gatherers.

## Опис проєкту

У цьому проєкті реалізовано програму для аналізу потоків транзакцій. Вона дозволяє знаходити першу транзакцію, сума якої перевищує заданий поріг, вибирати транзакції в межах встановленого бюджету та розподіляти їх на пакети заданого розміру. Для цього використовуються Java Stream API, Optional та власний Gatherer. Також програма може працювати з нескінченними потоками даних і завершувати їх обробку після виконання заданих умов. Крім того, передбачено перевірку вхідних параметрів, щоб уникнути помилок під час роботи програми.

## Визначення варіанта

Варіант визначається за порядковим номером у списку групи.

**Номер у списку:** 9

**Розрахунок:** V = 9 mod 3 = 0

**Варіант 0:** Електронна комерція та стрім транзакцій.

## Тестування

Для перевірки роботи програми написано модульні тести з використанням JUnit 5. Вони перевіряють правильність пошуку транзакцій, дотримання заданого бюджету та формування пакетів. Також перевіряється робота з нескінченними потоками, порожніми послідовностями та некоректними аргументами. Для тестів із нескінченними потоками встановлено обмеження часу виконання, щоб перевірити, чи завершується їх обробка.

## Запуск тестів

Для запуску тестів необхідно мати встановлену JDK 25. У проєкті використовується Gradle Wrapper, за допомогою якого можна запускати тести без окремого встановлення Gradle.

Для запуску потрібно відкрити термінал у кореневій папці проєкту та виконати відповідну команду.

`.\gradlew.bat test`

Після виконання команди Gradle запускає тести та показує результати їх виконання.
